# 电路模型

## 是什么
电路模型是用理想电路元件及其组合来近似替代实际电路器件，反映其电磁性能的抽象模型。实际电阻器、电感器、电容器等在一定条件下可分别用理想电阻、理想电感、理想电容等元件表示。

## 为什么需要它
- 简化分析：实际器件电磁过程复杂，用理想元件组合可建立数学方程求解。
- 统一描述：不同物理器件若具有相同电磁特性，可用同一电路模型表示。
- 工程基础：电路分析、设计与仿真均建立在电路模型之上。

## 核心公式
理想电路元件：
- 电阻：u = Ri
- 电感：u = L di/dt
- 电容：i = C du/dt
- 电压源：u = u_S
- 电流源：i = i_S

# 电路的变量

## 是什么
电路的变量主要指电压、电流和功率。电压是两点间电位差，电流是电荷定向移动速率，功率是能量转换速率。它们均为时间函数，需在参考方向下描述。

## 为什么需要它
- 描述状态：电压电流确定电路各点的工作状态。
- 建立方程：KCL、KVL及元件伏安关系均以电压电流为变量。
- 能量分析：功率和能量是电路性能评估的核心指标。

## 核心公式
u = dW/dq
i = dq/dt
p = dW/dt = ui

其中：
- u：电压（V）
- i：电流（A）
- p：功率（W）
- W：能量（J）
- q：电荷（C）

# 基尔霍夫定律

## 是什么
基尔霍夫定律包括电流定律（KCL）和电压定律（KVL）。KCL：任一节点处流入电流之和等于流出电流之和；KVL：任一回路沿绕行方向各段电压代数和为零。

## 为什么需要它
- 拓扑约束：只与电路连接方式有关，与元件性质无关。
- 独立方程：为节点电压法、回路电流法提供独立方程。
- 普适性：适用于任何集总参数电路，是电路分析的基础。

## 核心公式
KCL：
sum(i_k) = 0

KVL：
sum(u_k) = 0

# 电阻

## 是什么
电阻是表示导体对电流阻碍作用的理想元件，其伏安关系满足欧姆定律。电阻元件消耗电能并转化为热能，是无源元件。

## 为什么需要它
- 限流分压：电阻用于限制电流、分配电压。
- 能量转换：将电能转化为热能，实现加热、照明等。
- 电路模型：实际电阻器、导线损耗等均可用电阻表示。

## 核心公式
欧姆定律：
u = Ri

功率：
p = ui = i^2 R = u^2 / R

其中：
- R：电阻（欧姆）
- u：电压（V）
- i：电流（A）

# 电压源

## 是什么
电压源是端电压恒等于给定值 u_S 或按给定规律变化的理想元件，其输出电流由外电路决定。理想电压源内阻为零。

## 为什么需要它
- 提供电压：为电路提供恒定或变化的电压激励。
- 电路模型：实际电源（电池、发电机等）可近似为电压源与内阻串联。
- 分析简化：理想电压源端电压不随负载变化，便于分析。

## 核心公式
u = u_S

理想电压源：
- 端电压恒定（或按给定规律变化）
- 电流由外电路决定
- 内阻 R_S = 0

# 电流源

## 是什么
电流源是输出电流恒等于给定值 i_S 或按给定规律变化的理想元件，其端电压由外电路决定。理想电流源内阻为无穷大。

## 为什么需要它
- 提供电流：为电路提供恒定或变化的电流激励。
- 电路模型：某些电子器件（如晶体管）可近似为电流源。
- 分析简化：理想电流源输出电流不随负载变化，便于分析。

## 核心公式
i = i_S

理想电流源：
- 输出电流恒定（或按给定规律变化）
- 端电压由外电路决定
- 内阻 R_S = 无穷大

# 受控源

## 是什么
受控源（非独立源）是电压或电流的大小和方向受电路中另一支路电压或电流控制的电源。分为四类：电压控制电压源（VCVS）、电压控制电流源（VCCS）、电流控制电压源（CCVS）、电流控制电流源（CCCS）。

## 为什么需要它
- 电子器件模型：晶体管、运算放大器等有源器件可用受控源建模。
- 电路分析：含受控源电路需用KCL、KVL及控制关系联立求解。
- 信号放大：受控源可表示信号放大、反馈等物理过程。

## 核心公式
- VCVS：u_2 = mu * u_1
- VCCS：i_2 = g_m * u_1
- CCVS：u_2 = r_m * i_1
- CCCS：i_2 = beta * i_1

其中 mu 为电压放大倍数，g_m 为转移电导，r_m 为转移电阻，beta 为电流放大倍数。

# 分压公式

## 是什么
分压公式用于计算串联电阻电路中各电阻上的电压分配。串联电阻两端总电压按各电阻阻值比例分配。

## 为什么需要它
- 快速计算：无需列写KCL、KVL方程，直接求串联电阻分压。
- 电路设计：用于设计分压器、偏置电路等。
- 简化分析：将复杂串联电路等效化简后求某元件电压。

## 核心公式
两个电阻串联：
u_1 = (R_1 / (R_1 + R_2)) * u
u_2 = (R_2 / (R_1 + R_2)) * u

一般形式（n 个电阻串联）：
u_k = (R_k / sum(R_j)) * u

# 分流公式

## 是什么
分流公式用于计算并联电阻电路中各支路的电流分配。并联电阻总电流按各电阻电导（或阻值倒数）比例分配。

## 为什么需要它
- 快速计算：无需列写KCL、KVL方程，直接求并联电阻分流。
- 电路设计：用于设计分流器、电流分配网络等。
- 简化分析：将复杂并联电路等效化简后求某支路电流。

## 核心公式
两个电阻并联：
i_1 = (R_2 / (R_1 + R_2)) * i
i_2 = (R_1 / (R_1 + R_2)) * i

一般形式（n 个电阻并联）：
i_k = (G_k / sum(G_j)) * i

其中 G = 1/R 为电导。

# 支路电流法

## 是什么
支路电流法是以各支路电流为未知量，应用KCL和KVL列写方程求解电路的方法。对 b 条支路、n 个节点的电路，需列 n-1 个KCL方程和 b-(n-1) 个KVL方程。

## 为什么需要它
- 通用方法：适用于任何集总参数电路，尤其是含受控源电路。
- 直接求解：以支路电流为变量，物理意义明确。
- 基础方法：是节点电压法、回路电流法等方法的基础。

## 核心公式
KCL方程数：
n - 1

KVL方程数：
b - (n - 1)

总计：
(n - 1) + [b - (n - 1)] = b

其中：
- b：支路数
- n：节点数
