## 3.1 顺序程序设计概述

**顺序结构**：程序按照语句书写的先后顺序，从上到下依次执行。

特点：

- 每条语句执行一次
- 没有跳转、没有分支、没有循环
- 是最简单、最基本的程序结构

> [!info] 顺序结构的核心
> 输入数据 → 处理数据 → 输出结果

## 3.2 数据表现形式

### 3.2.1 常量

**常量**：在程序运行过程中，值不能被改变的量。

常见常量类型：

| 类型 | 示例 | 说明 |
|---|---|---|
| 整型常量 | `100`、`-5`、`0` | 十进制、八进制、十六进制 |
| 实型常量 | `3.14`、`-0.5`、`1.2e3` | 小数形式、指数形式 |
| 字符常量 | `'A'`、`'1'`、`'\n'` | 单引号括起来，只能一个字符 |
| 字符串常量 | `"hello"`、`"C语言"` | 双引号括起来 |
| 符号常量 | `#define PI 3.14159` | 用宏定义表示 |

### 3.2.2 变量

**变量**：在程序运行过程中，值可以改变的量。

变量必须先定义，后使用。

```c
int a;        // 定义整型变量 a
float b;      // 定义实型变量 b
char c;       // 定义字符型变量 c
```

> [!warning] 注意
> - 变量名区分大小写
> - 变量名不能以数字开头
> - 变量名不能使用 C 语言关键字
> - 变量必须先赋值再使用，否则值是随机的

## 3.3 基本数据类型

C 语言的基本数据类型：

| 类型 | 关键字 | 典型字节数 | 说明 |
|---|---|---|---|
| 整型 | `int` | 4 | 整数 |
| 短整型 | `short` | 2 | 短整数 |
| 长整型 | `long` | 4 或 8 | 长整数 |
| 无符号整型 | `unsigned int` | 4 | 非负整数 |
| 单精度实型 | `float` | 4 | 小数 |
| 双精度实型 | `double` | 8 | 更高精度小数 |
| 字符型 | `char` | 1 | 单个字符 |

### 3.3.1 整型数据

```c
int a = 10;
short b = 20;
long c = 100000L;
unsigned int d = 30;
```

### 3.3.2 实型数据

```c
float x = 3.14f;
double y = 3.1415926;
```

> [!tip] 实型常量默认是 double
> 如果要用 float，通常加后缀 `f`，如 `3.14f`。

### 3.3.3 字符型数据

```c
char ch = 'A';
char newline = '\n';
```

字符型数据在内存中存的是 **ASCII 码**。

常用转义字符：

| 转义字符 | 含义 |
|---|---|
| `\n` | 换行 |
| `\t` | 制表符 |
| `\\` | 反斜杠 |
| `\'` | 单引号 |
| `\"` | 双引号 |
| `\0` | 空字符 |

## 3.4 运算符与表达式

### 3.4.1 算术运算符

| 运算符 | 含义 | 示例 |
|---|---|---|
| `+` | 加 | `a + b` |
| `-` | 减 | `a - b` |
| `*` | 乘 | `a * b` |
| `/` | 除 | `a / b` |
| `%` | 取余 | `a % b` |
| `++` | 自增 | `a++`、`++a` |
| `--` | 自减 | `a--`、`--a` |

> [!warning] 整数除法
> 两个整数相除，结果仍是整数，小数部分被截断。
> ```c
> int a = 5 / 2;   // a = 2
> double b = 5.0 / 2; // b = 2.5
> ```

### 3.4.2 赋值运算符

```c
a = 10;      // 简单赋值
a += 5;      // 等价于 a = a + 5
a -= 3;      // 等价于 a = a - 3
a *= 2;      // 等价于 a = a * 2
a /= 4;      // 等价于 a = a / 4
a %= 3;      // 等价于 a = a % 3
```

### 3.4.3 关系运算符

| 运算符 | 含义 |
|---|---|
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于等于 |
| `<=` | 小于等于 |
| `==` | 等于 |
| `!=` | 不等于 |

关系运算的结果是 `1`（真）或 `0`（假）。

### 3.4.4 逻辑运算符

| 运算符 | 含义 | 说明 |
|---|---|---|
| `&&` | 逻辑与 | 两边都为真才为真 |
| `\|\|` | 逻辑或 | 一边为真就为真 |
| `!` | 逻辑非 | 真变假，假变真 |

### 3.4.5 运算符优先级

从高到低大致为：

```text
!  →  算术运算符  →  关系运算符  →  &&  →  ||  →  赋值运算符
```

> [!tip] 记忆口诀
> 先算算术，再比大小，再判逻辑，最后赋值。

## 3.5 类型转换

### 3.5.1 自动类型转换

不同类型数据运算时，精度低的会向精度高的转换。

```text
char → short → int → long → float → double
```

```c
int a = 10;
double b = 3.5;
double c = a + b;   // a 自动转为 double
```

### 3.5.2 强制类型转换

```c
(double)a;      // 把 a 转成 double
(int)3.14;      // 结果为 3
```

> [!warning] 注意
> 强制类型转换只是临时转换，不改变原变量类型。

## 3.6 数据的输入输出

### 3.6.1 `printf` 函数

格式：

```c
printf("格式控制字符串", 输出项列表);
```

常用格式字符：

| 格式字符 | 含义 |
|---|---|
| `%d` | 十进制整数 |
| `%f` | 浮点数 |
| `%c` | 单个字符 |
| `%s` | 字符串 |
| `%o` | 八进制 |
| `%x` | 十六进制 |
| `%%` | 输出一个 `%` |

示例：

```c
#include <stdio.h>

int main(void)
{
    int a = 10;
    float b = 3.14f;
    char c = 'A';

    printf("a = %d\n", a);
    printf("b = %f\n", b);
    printf("c = %c\n", c);

    return 0;
}
```

### 3.6.2 `scanf` 函数

格式：

```c
scanf("格式控制字符串", 地址列表);
```

> [!warning] 重点
> `scanf` 中的变量前必须加 `&`，表示取地址。
> 字符串数组名除外。

示例：

```c
#include <stdio.h>

int main(void)
{
    int a;
    float b;

    scanf("%d", &a);
    scanf("%f", &b);

    printf("a = %d, b = %f\n", a, b);

    return 0;
}
```

### 3.6.3 字符输入输出

```c
char ch;

ch = getchar();   // 输入一个字符
putchar(ch);      // 输出一个字符
```

## 3.7 顺序程序设计示例

### 3.7.1 例 1：求两个整数之和

```c
#include <stdio.h>

int main(void)
{
    int a, b, sum;

    printf("请输入两个整数：");
    scanf("%d%d", &a, &b);

    sum = a + b;

    printf("sum = %d\n", sum);

    return 0;
}
```

### 3.7.2 例 2：求圆的面积

```c
#include <stdio.h>

#define PI 3.14159

int main(void)
{
    double r, area;

    printf("请输入半径：");
    scanf("%lf", &r);

    area = PI * r * r;

    printf("面积 = %.2f\n", area);

    return 0;
}
```

### 3.7.3 例 3：温度转换

华氏温度转摄氏温度：

```text
C = (F - 32) * 5 / 9
```

```c
#include <stdio.h>

int main(void)
{
    double f, c;

    printf("请输入华氏温度：");
    scanf("%lf", &f);

    c = (f - 32) * 5 / 9;

    printf("摄氏温度 = %.2f\n", c);

    return 0;
}
```

### 3.7.4 例 4：交换两个变量的值

```c
#include <stdio.h>

int main(void)
{
    int a = 10, b = 20, temp;

    temp = a;
    a = b;
    b = temp;

    printf("a = %d, b = %d\n", a, b);

    return 0;
}
```

## 3.8 本章小结

- 顺序结构是最基本的程序结构
- C 语言基本数据类型：整型、实型、字符型
- 常量不可变，变量可变
- 运算符包括算术、赋值、关系、逻辑等
- 不同类型运算会发生自动类型转换，也可强制转换
- `printf` 用于输出，`scanf` 用于输入
- `scanf` 中变量前要加 `&`
