## 1.1 什么是程序

**程序**：一组计算机能识别和执行的指令，用于完成特定任务。

- 程序 = 数据结构 + 算法
- 数据结构：数据在计算机中的组织方式
- 算法：解决问题的步骤和方法

> [!info] 程序设计的核心
> 程序设计 = 设计数据结构 + 设计算法 + 用某种语言编写代码 + 调试运行

---

## 1.2 计算机语言的发展

| 阶段 | 语言类型 | 特点 |
|---|---|---|
| 第一代 | 机器语言 | 二进制指令，计算机直接执行，难写难读 |
| 第二代 | 汇编语言 | 用助记符代替二进制，仍需汇编器翻译 |
| 第三代 | 高级语言 | 接近自然语言和数学公式，可移植性好 |
| 第四代 | 非过程化语言 | 只说明“做什么”，不强调“怎么做” |
| 第五代 | 智能语言 | 面向人工智能、知识推理等 |

C 语言属于**高级语言**，但也具有低级语言的一些特点，比如可以直接操作内存。

---

## 1.3 C 语言的发展与特点

### 1.3.1 发展简史

- 1972—1973 年，Dennis Ritchie 在贝尔实验室设计并实现 C 语言
- 1978 年，Kernighan 和 Ritchie 出版《The C Programming Language》，即 K&R C
- 1983 年，ANSI 制定 C 标准，称为 ANSI C / C89
- 后续标准：C99、C11、C17、C23

### 1.3.2 C 语言特点

> [!tip] C 语言的主要特点
> - 简洁、紧凑、灵活
> - 运算符丰富
> - 数据类型丰富
> - 具有结构化的控制语句
> - 允许直接访问物理地址，能进行位运算
> - 生成目标代码质量高，程序执行效率高
> - 可移植性好

## 1.4 最简单的 C 程序

### 1.4.1 例 1：输出一行文字

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, world!\n");
    return 0;
}
```

### 1.4.2 程序结构分析

```c
#include <stdio.h>   // 预处理指令：包含标准输入输出头文件

int main(void)       // 主函数，程序入口
{
    printf("Hello, world!\n");  // 调用 printf 输出
    return 0;                   // 返回 0，表示程序正常结束
}
```

> [!note] 关键点
> - 每个 C 程序都必须有且只有一个 `main` 函数
> - 程序从 `main` 开始执行，也在 `main` 结束
> - `#include` 是预处理指令，不是 C 语句，末尾不加分号
> - C 语言区分大小写
> - 每条语句通常以分号 `;` 结束

## 1.5 C 程序的组成

一个 C 程序可以由以下部分组成：

1. 预处理指令，如 `#include <stdio.h>`
2. 全局声明
3. 函数定义
4. 注释

### 1.5.1 函数的一般形式

```c
返回类型 函数名(参数列表)
{
    声明部分
    执行部分
}
```

### 1.5.2 例 2：求两个整数之和

```c
#include <stdio.h>

int main(void)
{
    int a, b, sum;

    a = 10;
    b = 20;
    sum = a + b;

    printf("sum = %d\n", sum);

    return 0;
}
```

## 1.6 运行 C 程序的步骤

```text
源程序 .c
   ↓ 编译预处理
预处理后的源程序
   ↓ 编译
目标程序 .obj / .o
   ↓ 链接
可执行程序 .exe / a.out
   ↓ 运行
结果
```

> [!info] 常见工具
> - Windows：Dev-C++、Code::Blocks、Visual Studio、VS Code + MinGW
> - Linux/macOS：gcc、clang
> - 在线：Compiler Explorer、OnlineGDB

### 1.6.1 用 gcc 编译运行

```bash
gcc hello.c -o hello
./hello
```

## 1.7 注释

```c
// 单行注释

/*
   多行注释
   可以写很多行
*/
```

> [!warning] 注意
> - 注释不能嵌套
> - 注释用于解释代码，不参与编译

## 1.8 本章小结

- 程序是计算机能识别和执行的指令集合
- C 语言是高级语言，简洁、高效、可移植
- C 程序由函数组成，必须有 `main` 函数
- C 程序运行需要经过：编辑 → 编译 → 链接 → 运行
- 学会使用 `printf` 输出，使用 `return 0` 结束程序
